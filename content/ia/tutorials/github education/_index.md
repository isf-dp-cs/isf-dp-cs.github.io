# GitHub Education
GitHub Education provides many free resources for students, including AI-powered copilot. 



---

## [0] Application  

[Apply here](https://github.com/education/students) to get GitHub Education. It may take a few days to get verified. 

---

## [1] GitHub Copilot

In general, you can use GitHub Copilot [here.](https://github.com/copilot)   

### Adding IntelliJ Plugin

1. Press `⌘` `,` to open settings and then select *Plugins*.

2. Click the *Marketplace* tab and type "GitHub Copilot"in the search field.

3. To install the plugin, click *Install* and restart IntelliJ IDEA.

### Adding VSCode Extension

1. Press `⌘` `shift` `X` to open *Extensions*.

2. Type "GitHub Copilot"in the search field.

3. To install the plugin, click *Install* and restart VSCode.


### Other Editors

For other editors, checkout [this page on GitHub's website](https://docs.github.com/en/copilot/using-github-copilot/getting-code-suggestions-in-your-ide-with-github-copilot?tool=vscode)
